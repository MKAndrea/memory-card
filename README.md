# 🃏 Gioco del Memory Card

Benvenuto nel **Memory Card**, il classico gioco da tavolo che mette alla prova la tua memoria visiva e i tuoi riflessi!

---

## 🎮 Di cosa si tratta?

Sul tavolo ci sono diverse carte coperte a faccia in giù con simboli divertenti (animali, cibo, spazio, videogiochi...). 
L'obiettivo è scoprire tutte le carte trovando le coppie identiche!

### 🌟 Modalità di Gioco:

1. **👥 Modalità Sfida a Coppie (2 Giocatori)**:
   - Perfetta per giocare con un amico o un compagno sullo stesso computer!
   - I giocatori si alternano a turni: clicchi su due carte per scoprirle.
   - **Se trovi la coppia**: guadagni 1 punto, le carte si illuminano del tuo colore (🔵 **Blu** per il Giocatore 1, 🔴 **Rosa** per il Giocatore 2) e hai diritto a giocare subito un altro turno!
   - **Se sbagli**: le carte tornano coperte dopo un secondo e il turno passa al compagno.
   - Vince chi conquista più coppie alla fine della partita!

2. **👤 Modalità Singolo**:
   - Vuoi allenare la mente da solo? Puoi giocare in solitario cercando di completare il mazzo nel minor numero di tentativi possibile.

3. **🎛️ Scegli quante carte usare**:
   - Tramite il menu a tendina in alto puoi decidere la grandezza del tavolo:
     - **8 Carte**: partita super veloce (4 coppie)
     - **12 o 16 Carte**: partita classica ed equilibrata
     - **20 o 24 Carte**: la sfida massima per veri campioni di memoria!

---

## 🚀 Come avviare il gioco (Passo dopo Passo)

Non serve alcuna competenza tecnica per farlo partire! Basta seguire questi 4 semplici passaggi:

### 1. Apri la cartella nel terminale
Apri la cartella del progetto `memory-card` nel prompt dei comandi, PowerShell o nel terminale del tuo editor.

### 2. Installa il necessario (solo la prima volta)
Digita questo comando e premi **Invio**:
```bash
npm install
```
*(Questo comando scaricherà in automatico i componenti necessari al funzionamento del gioco)*.

### 3. Avvia il gioco
Digita questo comando e premi **Invio**:
```bash
npm run dev
```

### 4. Gioca nel tuo Browser!
Nel terminale comparirà un indirizzo (di solito `http://localhost:5173/`). 
Cliccaci sopra oppure copialo nel tuo browser preferito (Chrome, Edge, Safari...) per iniziare subito a giocare! 🎉
